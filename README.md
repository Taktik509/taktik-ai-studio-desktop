# Taktik AI Studio — Desktop App

Native desktop apps for **Windows**, **macOS** (Intel + Apple Silicon) and **Linux**.
No browser needed — open your Taktik workspace directly on your computer.

Download the latest version from the [**Releases**](https://github.com/Taktik509/taktik-ai-studio-desktop/releases) page.

## Features

- Opens straight into your Taktik dashboard — log in once, stay signed in
- Native menus (Dashboard, AI Tools, Flow Studio, Billing, Sign out)
- **Offline Toolkit** (works without internet): Hook Lab, CTA Builder, Playbooks, Content Calendar, Caption Formatter
- System tray, download manager, zoom controls, notifications
- Automatic updates from new releases published here

## Install

| Platform | File |
|---|---|
| Windows 10/11 (64-bit) | `Taktik-AI-Studio-*-win-portable.zip` — unzip & double-click, no install needed |
| macOS Intel | `Taktik-AI-Studio-*-mac-x64.zip` |
| macOS Apple Silicon | `Taktik-AI-Studio-*-mac-arm64.zip` |
| Linux (any distro) | `Taktik-AI-Studio-*.AppImage` — make executable & run |
| Linux (Debian/Ubuntu) | `Taktik-AI-Studio-*.deb` |
